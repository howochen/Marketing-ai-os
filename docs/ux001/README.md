# MOS-UX-001：首次設定精靈

本次只重排 `/app/automation` 既有欄位與既有政策／Key API；沒有新增 Schema、Provider、OAuth、Key 儲存或背景服務。

## 操作

1. **品牌設定**：填寫品牌與產業，免費預覽後套用；畫面顯示「品牌建議已套用」。可修改全部欄位，建議不等於核實品牌事實。
2. **連接 AI**：既有設定可直接選取；已保存 Key 顯示綠色狀態、不要求重填。新設定必須先到第三步保存完整設定，成功後自動返回此步，使用原 HTTPS Key API 安全保存。
3. **自動發文設定**：設定帳號、模式、篇數、時段、預算與期限。按「儲存設定（不啟用發文）」只建立未啟用的設定。真實測試與持續發布仍須原有獨立授權。

既有設定不會被精靈自動修改；「複製為新版」仍使用原版本機制。新版本的 Key 綁定與原本相同，不會偷偷搬移憑證或授權。

## 驗證

- 實際 HTTP／SQLite 瀏覽器流程：AJ 範例 → 套用 → OpenAI → 草稿 201 → Key 失敗保留 → 重試保存 → 綠色狀態 → 重開頁面無須重填。
- 測試 Key 只為合成字串；403 注入測試未送出 Key，成功路徑使用隔離資料庫現有加密 API。
- `evidence.json`：1440／768／390 寬度均無橫向溢出；實際滑鼠點擊三步驟。
- 既有針對性 pytest 19 passed；Node 9 passed；mypy 36 模組無錯誤。完整回歸及漏洞掃描由該 SHA GitHub Actions 執行。
- 無新增依賴；真實 AI 呼叫 0，真實發文 0，API 費用 USD 0。
- `browser-check.mjs` 為可重跑的隔離瀏覽器檢查：啟動既有合成 preview 後，設定 `MOS_CDP_HELPER` 為已安裝 CDP helper 的 file URL，再執行 Node。正式驗證僅讀取已存設定，不寫入既有政策或 Key。

## 限制

手機尺寸使用隔離 Chromium 驗證，未在實體 iPhone Safari 操作。Key 安全保存不代表模型權限或付費生成測試已成功；全自動真實發文未驗收。
