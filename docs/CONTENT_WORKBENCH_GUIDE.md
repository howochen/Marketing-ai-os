# 行銷內容工作台：操作說明

## 開啟本機工作台

在專案資料夾雙擊 `Start-Content.cmd`。若尚未安裝 Python 環境，由管理員先執行 `python -m venv .venv`，再執行 `.venv\Scripts\python -m pip install -r requirements-dev.txt`。

啟動器會開啟 **http://127.0.0.1:8893/app/content**。將本機視窗顯示的十分鐘一次性登入碼貼入登入畫面；這沿用既有認證，不是 Meta App Secret。不要轉傳登入碼。關閉該視窗即停止服務；再次雙擊會產生新登入碼，保留原內容。

資料保存在忽略的 `.content-local/content.db`，不是既有 Docker PostgreSQL 或 `.threads-local`。不要刪除 `.content-local`；有資料後，先關閉服務，再備份整個資料夾至受控儲存。此本機工作區不適合多人共用或公開營運。

這個網址只能在 Windows 本機使用，**不能在 iPhone 的127.0.0.1開啟**。手機須使用由管理員部署新版後的受控 HTTPS `/app/content`，搭配原有登入碼／租戶認證。此次沒有更改既有 ngrok、OAuth、DPAPI 或公開容器；不會自動把工作台公開。

## 人工內容流程

1. 進入「內容工作台」，按「建立內容任務」。填品牌介紹、產業、客群、主題、目的、語氣、必要詞、禁止詞與字數上限。關鍵字可用逗號分隔。這只建立既有 Task，沒有 AI 生成。
2. 輸入全文、Hook、CTA。Hook與CTA應是全文中的原句；欄位不會自動附加到全文。按「儲存第一版並檢查QA」。全文限制以Unicode字元計算，含空白、換行，不是模型Token。
3. 查看品質審查。PASS／FAIL只表示確定性規則；UNEVALUATED需人工判斷。命中禁止詞或其他硬性規則必須修訂，不能用人工高分繞過。AI生成按鈕保持停用。
4. 修改文字並填至少5字元的修訂原因，按「儲存為新版本」。版本歷史保留全文、Hook與CTA；「比較版本」可比較任意兩版。「載入此版另存」只載入文字，儲存後才建立新的待審版本。
5. 擁有者人工閱讀完整內容後，按「已人工檢閱，核准此版本」。核准只適用畫面指定的Revision。其他角色無法核准；撤銷會保留審計。修改後須再次核准。
6. 最新版核准後，可填發布日期時間、IANA時區（預設Asia/Taipei）、指定或待指定帳號及備註，按「保存發布計畫」。這會建立MANUAL_REQUIRED Publication及不可覆寫計畫，**不會啟動自動發布**。未連接帳號會顯示「等待帳號連接」。

本機啟動器使用既有擁有者登入流程，預算為0，模型／社群HTTP／發布／手機初始化均強制關閉。受控多人部署沿用原來的Owner、Manager、Reviewer、Worker權限，不使用本機啟動器替代正式身分管理。

## 常見問題

- **需要修改品牌需求**：第一版文案建立前，可按「修改需求」。建立Revision後需求鎖定；若品牌限制改變，請新建任務，避免已審內容被偷換限制。
- **另一人已修改**：伺服器回409，不覆寫新版本；您的輸入保留。先複製文字，再重新讀取任務與比較，合併後另存。不提供自動覆蓋。
- **有未儲存文字**：切換／離開頁面會提醒；請不要忽略提醒。未儲存內容不寫入localStorage，瀏覽器崩潰仍可能遺失。
- **舊任務沒有版本**：已存在輸出的待審／已核准任務，可按「載入既有文案並建立快照」。歷史來源會標LEGACY_UNVERIFIED或既有Mock來源，不能偽稱人工或真實AI；快照重新待審。沒有原始輸出的舊任務不製造假文案。
- **日期被拒絕**：日期須在未來；使用有效IANA時區。夏令時間重複或不存在的當地時間會拒絕，請改選明確時段。
- **計畫顯示需重新核准**：該精確Revision已非目前核准版，或核准已撤銷。舊計畫不會自動指向新文案；重新核准新版並另存計畫。
- **登入失效／API錯誤**：畫面顯示錯誤，伺服器不會自動改用其他帳號、模型或發布。請先保存可複製的未儲存文字，再取得新登入碼。

本階段不代表實際AI文案品質、真實Threads發布、法規合規或正式營運安全性已驗證。
